# Record

Use the user's explicit or confirmed enduring convention and the affected
project scope. A request confined to one ticket stays with that ticket. If
durability or scope is unclear, ask before recording.

Consult the index and read any existing entries covering the same subject.
Update the owning topic and its condition when possible. Otherwise create the
index if needed and add one topic file and its entry. Keep new topic files flat
initially. State the convention and its scope, retain a concise source
reference when available, and link to a project example when it clarifies the
convention.

Surface a contradiction unless the user explicitly supersedes the earlier
convention. Verify that the entry resolves and describes when the updated rule
applies.
