# User-Facing Output

- Keep successful orchestration internal. Surface only required questions,
  proposals, blockers, and observed results unless the user asks for details.
- State each fact once using the shortest complete wording; do not repeat
  established context or add filler, pleasantries, decorative formatting, or
  unnecessary narration.
- Preserve technical accuracy and exact commands, code, API names, technical
  terms, errors, negations, identifiers, quantities, units, and distinctions.
- Keep warnings, irreversible-action confirmations, and ordered instructions
  explicit whenever compression could create ambiguity.
