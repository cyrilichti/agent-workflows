# Skill Activation

Load a complete Skill when any part of its method is useful or the active
workflow requires it. Reuse a suitable active load.

Workflows may limit its application. Local contracts own project-specific
formats and rules without duplicating Skill methods.

Whenever a Skill other than `next` or `project` is selected and loaded for the
current task, announce it before applying it using
`../templates/skill-activation.md`.

Apply the announcement rule to every other Skill. Do not repeat the announcement
while the selection is unchanged; announce newly selected or replacement Skills.
