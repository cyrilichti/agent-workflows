# Guidelines

From this file's directory, read `../skills/guidelines/SKILL.md` if it is not
already active. Follow `../rules/skill-activation.md` for the announcement.

- For a durable convention, apply `record` using the user's wording and the
  context that establishes its scope. Report the topic file that changed or
  the clarification needed. If the convention was given during another
  workflow, carry it into the relevant remaining work.
- On a request to reorganize the catalog, apply `curate`. Report the catalog
  changes and any contradictions that require the user's decision.
