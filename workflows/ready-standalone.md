# Ready Standalone Branch

### 1. Initialize the Delivery Context

Follow `./delivery-context-standalone.md`, then follow `./ready-confirm.md` with
its plan, item, and delivery context. That branch resolves the exact request,
asking for its ID only when no unique identity is available.

```text
plan: selected plan
item: selected complete official item context
delivery_context: initialized delivery context
```
