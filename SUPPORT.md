# Support

## Getting help

Start with the [installation guide](https://cyrilichti.github.io/agent-workflows/installation/), [provider setup](https://cyrilichti.github.io/agent-workflows/providers/), and [workflow reference](https://cyrilichti.github.io/agent-workflows/workflows/).

## Report a problem

Open a [GitHub issue](https://github.com/cyrilichti/agent-workflows/issues) for reproducible bugs, unclear documentation, or questions that the documentation does not answer. Include the command or workflow you ran, the expected result, and the observed result.

## Propose an improvement

Open a GitHub issue to discuss a workflow, skill integration, or documentation improvement before preparing a pull request. Read [CONTRIBUTING.md](./CONTRIBUTING.md) for contribution expectations.

## Security concerns

Do not open a public issue. Follow the private reporting process in [SECURITY.md](./SECURITY.md).
