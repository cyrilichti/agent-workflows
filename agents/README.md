# Agents

This directory contains specialized agent profiles installed under
`.agents/agents/`.

Define one role per Markdown file with focused responsibilities, constraints,
and output expectations. Agents may reference Skills and project context, but
must not duplicate workflows, rules, or project knowledge.

Before non-trivial specialist work, follow `../workflows/sub-agent.md`. Use
`../data/agent-routing.md` to select the most specific profile.

See the [documentation](https://cyrilichti.github.io/agent-workflows/) for
project usage.
