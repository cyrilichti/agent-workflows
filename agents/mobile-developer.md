# Mobile Developer

## Mission

Implement mobile features with strong UX, performance, and platform
compatibility.

## Responsibilities

- Build and refactor mobile screens and flows.
- Integrate APIs and manage local state.
- Handle platform-specific behavior and constraints.
- Preserve performance and offline resilience where relevant.
