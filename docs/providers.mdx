## Item provider

Select ClickUp or Linear for item operations.

```yaml
mcp:
  item:
    provider: linear # or clickup
```

## Version provider

Select GitHub or GitLab for version operations.

```yaml
mcp:
  version:
    provider: github # or gitlab
```

## Configure provider access

ClickUp, Linear, and GitHub use their official MCP integrations. Enable the
integrations selected by the project in the AI client running the workflows:

- [Connect ClickUp's MCP server](https://developer.clickup.com/docs/connect-an-ai-assistant-to-clickups-mcp-server)
- [Connect Linear's MCP server](https://linear.app/docs/mcp)
- [Connect GitHub's MCP server](https://docs.github.com/en/copilot/how-tos/provide-context/use-mcp-in-your-ide)

GitLab operations use the official `glab` CLI instead of an MCP server. Install
[`glab`](https://docs.gitlab.com/cli/installation/), then authenticate it for
the repository's host before selecting GitLab:

```bash
glab auth login --hostname gitlab.example.com
```

For GitLab.com, run `glab auth login`. See GitLab's
[authentication guide](https://docs.gitlab.com/cli/authentication/) for OAuth,
personal access token, CI, and self-managed instance options.
