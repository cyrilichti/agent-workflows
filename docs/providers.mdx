## Item provider

Select ClickUp or Linear for item operations.

Use ClickUp:

```yaml
mcp:
  item:
    provider: clickup
```

Or use Linear:

```yaml
mcp:
  item:
    provider: linear
```

## Version provider

`/work` currently supports GitLab only for version operations:

```yaml
mcp:
  version:
    provider: gitlab
```

GitLab creates the draft merge request after `/work` pushes the new branch.
The current provider creates it without a description. GitHub is not supported
in this release.

## Connect the MCP servers

Enable the MCP servers matching the configured item and version providers in
the AI tool running the workflows. Setup depends on the client you use:

- [Connect ClickUp's MCP server](https://developer.clickup.com/docs/connect-an-ai-assistant-to-clickups-mcp-server)
- [Connect Linear's MCP server](https://linear.app/docs/mcp)
- [Connect GitLab's MCP server](https://docs.gitlab.com/user/gitlab_duo/model_context_protocol/mcp_server/)
