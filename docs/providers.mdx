## Item provider

Select ClickUp or Linear for item operations.

```yaml
mcp:
  item:
    provider: linear # or clickup
```

## Version provider

Select GitHub or GitLab for version operations.

```yaml
mcp:
  version:
    provider: github # or gitlab
```

## Connect the MCP servers

As a prerequisite, enable the official MCP servers matching the configured
item and version providers in the AI client running the workflows. Setup and
credentials depend on that client and remain outside `agent-workflows`:

- [Connect ClickUp's MCP server](https://developer.clickup.com/docs/connect-an-ai-assistant-to-clickups-mcp-server)
- [Connect Linear's MCP server](https://linear.app/docs/mcp)
- [Connect GitHub's MCP server](https://docs.github.com/en/copilot/how-tos/provide-context/use-mcp-in-your-ide)
- [Connect GitLab's MCP server](https://docs.gitlab.com/user/gitlab_duo/model_context_protocol/mcp_server/)
