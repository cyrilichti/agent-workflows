title: Workflows

import { CardGrid, LinkCard } from '@astrojs/starlight/components'

Use each Skill directly or combine them into a delivery flow. `/hotfix` and
`/pick` can take work through human plan approval and into autonomous delivery;
`/write`, `/refine`, and standalone `/plan` prepare work without starting it.
For parallel tickets in one project, `/sandbox` prepares isolated environments
and removes them afterward. `/work`, `/ready`, and `/inspect` can continue
through implementation and review, while a person decides when `/done` merges
the request and closes the item.
