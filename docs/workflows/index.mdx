---
title: Workflows
description: Eight entry points across one governed delivery chain.

import { CardGrid, LinkCard } from '@astrojs/starlight/components'

The workflows move the same work from ticket to merge. Shape and plan with
assisted workflows, approve the start of delivery, then let the autonomous loop
implement and review the change. `/done` remains a separate human decision.
