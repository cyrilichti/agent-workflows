---
title: Workflows
description: Controlled sequences of skills that move work forward.
---

import { CardGrid, LinkCard } from '@astrojs/starlight/components'

Each workflow puts the right skills in order, carries context forward, and
keeps approval and provider boundaries explicit.

The playbook checks these explicit lifecycle routes first. When none matches,
it passes the request context to optional specialist routing. A matching theme
retains or activates the appropriate profile; otherwise, the original request
continues without a profile or activation announcement.
