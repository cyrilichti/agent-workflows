title: /write
description: Create or improve one work item with the right writing skill for the current need.
---

`/write` turns an idea or an existing item into one clear work item. While the content is
being drafted or revised, it selects the external writing skill that best matches the current
need—clarification, product exploration, challenge, or specification.

## How this workflow is structured

After step 2 (mode selection), `/write` follows exactly one branch:

- **create**: destination and assignment, then `./write-confirm.md`
- **update**: existing item and assignment, then `./write-confirm.md`

The table below describes the full user journey across router, branch, and confirm:

<table class="workflow-steps">
  <tbody>
    <tr>
      <td>1</td>

      <td>Load the configured item provider.</td>

    <tr>
      <td>2</td>

      <td>Choose create or reformulate.</td>
    </tr>
    <tr>
      <td>3</td>

      <td>Find and read the existing item.</td>
    </tr>
    <tr>

      <td>Select where to create the item.</td>
    </tr>
    <tr>
      <td>5</td>
      <th scope="row">Draft</th>
      <td>Use the best-fit external skill to draft one item.</td>
    </tr>
    <tr>
      <td>6</td>

    <tr>
