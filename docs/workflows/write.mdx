---
title: /write
description: Create or improve one work item with the right writing skill for the current need.
---

`/write` qualifies one new or existing item before drafting it. For non-trivial
needs, it treats the initial description as working context, asks progressive
questions, challenges relevance, risks, assumptions, constraints, and success
criteria, then confirms a concise understanding summary. Only then does it
produce one complete item proposal. Purely mechanical work or an explicit
request for immediate drafting may take the direct path, but the title and body
still require confirmation before save.

The workflow reuses available conversation and project context to avoid mode,
intention, provider, and destination questions that are already answered. After
confirmation, it saves the item and applies `agent-shaped`; a label failure is
reported without failing the save. The label records use of `/write`, not
readiness, feasibility, or size.

## How this workflow is structured

<table class="workflow-steps">
  <tbody>
    <tr>
      <td>1</td>
      <th scope="row">Mode</th>
      <td>Infer create or reformulate from explicit intent, and ask only when the request is bare or ambiguous.</td>
    </tr>
    <tr>
      <td>2</td>
      <th scope="row">Context</th>
      <td>Reuse the available intention and item reference, resolve the configured provider through the active MCP runtime, and try an explicit destination or the current project name before asking.</td>
    </tr>
    <tr>
      <td>3</td>
      <th scope="row">Qualification</th>
      <td>For non-trivial needs, ask progressive contextual questions and challenge relevance, risks, assumptions, constraints, and success criteria before drafting.</td>
    </tr>
    <tr>
      <td>4</td>
      <th scope="row">Understanding</th>
      <td>Confirm one concise understanding summary. Suggest <code>to-spec</code> when its format would help, and activate it only after explicit acceptance.</td>
    </tr>
    <tr>
      <td>5</td>
      <th scope="row">Draft and review</th>
      <td>Produce one complete proposal after confirmed understanding, then adjust it or confirm its title and body for saving.</td>
    </tr>
    <tr>
      <td>6</td>
      <th scope="row">Save</th>
      <td>Save the confirmed content, apply `agent-shaped`, and report the result.</td>
    </tr>
  </tbody>
</table>
