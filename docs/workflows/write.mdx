---
title: /write
description: Create or improve one work item with the right writing skill for the current need.
---

`/write` turns an idea or an existing item into one clear work item. For a new item, it
starts from your need. For a reformulation, it first reads the selected item, then asks
what should change. It drafts with the external writing skill that best matches that
need—clarification, product exploration, challenge, or specification.

## How this workflow is structured

<table class="workflow-steps">
  <tbody>
    <tr>
      <td>1</td>
      <th scope="row">Mode</th>
      <td>Choose create or reformulate.</td>
    </tr>
    <tr>
      <td>2</td>
      <th scope="row">Context</th>
      <td>Create from a described need, or select and read the item to reformulate before describing the change.</td>
    </tr>
    <tr>
      <td>3</td>
      <th scope="row">Destination</th>
      <td>When creating, select where to create the item.</td>
    </tr>
    <tr>
      <td>4</td>
      <th scope="row">Draft</th>
      <td>Use the best-fit external skill for that need to draft one item.</td>
    </tr>
    <tr>
      <td>5</td>
      <th scope="row">Review</th>
      <td>Approve the item or return it for another writing pass.</td>
    </tr>
    <tr>
      <td>6</td>
      <th scope="row">Assignment</th>
      <td>Choose the assignment behavior.</td>
    </tr>
    <tr>
      <td>7</td>
      <th scope="row">Save</th>
      <td>Save the confirmed item and apply the assignment choice.</td>
    </tr>
  </tbody>
</table>
