---
title: /next
description: Find one eligible Linear or ClickUp item without starting work.
---

`/next` makes one filtered request to the item provider configured in
`agent-workflows.yaml` and returns its first result across all projects and
destinations. Linear filters for the exact `agent-shaped` label and `Backlog`
status. ClickUp filters for the `agent-shaped` tag and excludes closed tasks.

Invoke it as `/next` or `$next`, or let the Kestra `work` workflow call it
through the bridge. It needs no item reference.

The response is a JSON object containing only `name`, `id`, and `url`. If the
provider query finds none, it returns `{"status":"no eligible item"}`.
Provider errors are reported as errors. The workflow stops after selection;
it does not plan, start delivery, or change the item or repository.
