---
title: /next
description: Select one eligible item and return its identity and destination.
---

The `agent-planned` label or tag marks work whose approved plan is available on
its item. Eligible work is waiting to start, or is in review without
`agent-inspected`. `/next` selects the least recently modified eligible item
from the configured provider's first returned page. Equal timestamps retain
provider order. Each adapter maps provider statuses to that shared rule using
the selection response.

After human findings, remove `agent-inspected` to make a review item eligible
again. It keeps its plan and request. Updating it gives older eligible work a
turn in subsequent selections.

Invoke it as `/next` or `$next`, or let the Kestra `work` workflow call it
through the bridge. It needs no item reference.

## What `/next` does

<table class="workflow-steps">
  <tbody>
    <tr>
      <td>1</td>
      <th scope="row">Filter</th>
      <td>Both providers filter for <code>agent-planned</code> work. Status names are matched case-insensitively: <code>Backlog</code> or <code>Todo</code> for Linear, <code>Open</code> for ClickUp. For other names, the agent interprets whether their meaning is open or waiting to start, including localized names such as <code>ouvert</code>, without a fixed synonym list. Review items qualify only without <code>agent-inspected</code>. Work in progress, terminal, missing, and ambiguous states are skipped. Selection uses last-modified timestamps within the first page, even when more pages exist; provider order breaks ties.</td>
    </tr>
    <tr>
      <td>2</td>
      <th scope="row">Return</th>
      <td>A found item returns only <code>{'{"name":"…","id":"…","url":"…","list":"…"}'}</code>. <code>list</code> is the Linear project name or ClickUp list name. No match returns <code>{'{"status":"no eligible item"}'}</code>; a missing destination, provider failure, incomplete candidate labels, or invalid eligible timestamp is an error.</td>
    </tr>
    <tr>
      <td>3</td>
      <th scope="row">Stop</th>
      <td>Selection ends without reading another item, creating a plan, changing the ticket, or starting delivery. Use <a href="/agent-workflows/workflows/work/"><code>/work</code></a> to start delivery for the selected item.</td>
    </tr>
  </tbody>
</table>
