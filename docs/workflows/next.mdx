---
title: /next
description: Select one eligible item and return its identity and destination.
---

The `agent-planned` label marks work whose approved plan is available on its
item. `/next` selects the
first eligible item in the configured provider's returned page. It does not
choose the most recently created or updated item: neither provider query
specifies that ordering. The provider-specific status rules below narrow the
eligible set.

Invoke it as `/next` or `$next`, or let the Kestra `work` workflow call it
through the bridge. It needs no item reference.

## How `/next` selects

<div class="write-flow" role="group" aria-label="The next workflow resolves the configured item provider, runs one filtered selection query, then returns the first item's identity and destination or an empty result.">
  <div class="write-flow__step write-flow__step--assisted">
    <small>01 · Configure</small>
    <strong>Resolve item provider</strong>
    <span>Read the Linear or ClickUp selection from <code>agent-workflows.yaml</code>.</span>
  </div>

  <span class="write-flow__connector" aria-hidden="true">↓</span>

  <div class="write-flow__step write-flow__step--focus">
    <small>02 · Select</small>
    <strong>Query once</strong>
    <span>Apply the provider's eligibility rule and take the first eligible result.</span>
  </div>

  <span class="write-flow__connector" aria-hidden="true">↓</span>

  <div class="write-flow__step write-flow__step--assisted">
    <small>03 · Return</small>
    <strong>Return item</strong>
    <span>Return the item name, ID, URL, and destination, or report that no item matched.</span>
  </div>
</div>

## What `/next` does

<table class="workflow-steps">
  <tbody>
    <tr>
      <td>1</td>
      <th scope="row">Filter</th>
      <td>Linear selects the first unarchived issue in the returned page with the exact <code>agent-planned</code> label and a <code>Backlog</code> or <code>Open</code> status. ClickUp selects a task tagged <code>agent-planned</code> and excludes closed tasks.</td>
    </tr>
    <tr>
      <td>2</td>
      <th scope="row">Return</th>
      <td>A found item returns only <code>{'{"name":"…","id":"…","url":"…","list":"…"}'}</code>. <code>list</code> is the Linear project name or ClickUp list name. No match returns <code>{'{"status":"no eligible item"}'}</code>; a missing destination or provider failure is an error.</td>
    </tr>
    <tr>
      <td>3</td>
      <th scope="row">Stop</th>
      <td>Selection ends without reading another item, creating a plan, changing the ticket, or starting delivery. Use <a href="/agent-workflows/workflows/work/"><code>/work</code></a> to start delivery for the selected item.</td>
    </tr>
  </tbody>
</table>
