title: /work
description: Execute one selected plan todo by todo on a draft merge request.
---

`/work` turns an approved plan into confirmed commits. It can receive the plan
from `/pick` with an active official item, or let you select from recent plans.

## Dispatching agents

`/work` evaluates each active todo and routes it to the most suitable agent.
The selected agent implements and validates that todo, while `/work` keeps
control of sequencing, plan state, staging, and commits. The choice is
reevaluated for every todo.
