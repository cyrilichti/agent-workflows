title: /plan
description: Turn one delivery unit into an approved implementation plan.
---

`/plan` turns one task into an approved implementation plan. It first checks
that the task is one coherent delivery unit, routes the work to the right
specialist, and resolves every material question before asking for approval.
For an official item, an approved result then publishes the plan in a dedicated
comment, requires a successful publication response, and applies
<code>agent-planned</code>. A
<code>needs-refinement</code> result returns its findings directly to the caller
without publishing or labeling the item.

An explicit item ID, URL, or title is resolved as official item context. A
direct invocation still uses plan-only approval: it may publish an official
item plan, but it does not start delivery. When `/plan` is called by `/pick`,
approval also authorizes autonomous delivery and returns control to `/pick` so
it can continue with `/work`.

## What `/plan` does

<table class="workflow-steps">
  <tbody>
    <tr>
      <td>1</td>
      <th scope="row">Assess</th>
      <td>Continue for one delivery unit or return <code>needs-refinement</code> through the active context branch without creating or publishing a plan.</td>
    </tr>
    <tr>
      <td>2</td>
      <th scope="row">Plan</th>
      <td>Route to one specialist, inspect the relevant context, and write the plan.</td>
    </tr>
    <tr>
      <td>3</td>
      <th scope="row">Resolve</th>
      <td>Ask and incorporate every answer that could materially change the plan.</td>
    </tr>
    <tr>
      <td>4</td>
      <th scope="row">Approve</th>
      <td>Present the complete plan and revise it until the human approves it. Standalone approval completes only <code>/plan</code>; workflow approval returns to its caller with autonomous delivery authorized.</td>
    </tr>
    <tr>
      <td>5</td>
      <th scope="row">Publish</th>
      <td>For an official item, publish the approved plan, require the mutation response to identify the created comment, then apply <code>agent-planned</code>. Stop before labeling when publication fails or is inconclusive.</td>
    </tr>
  </tbody>
</table>
