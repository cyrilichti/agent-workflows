`/sandbox` creates an isolated environment for a work item and returns a context
you can use to remove it later.

## Docker setup

After [installing `sbx`](https://docs.docker.com/ai/sandboxes/install/), allow
network access so the sandbox can pull the images required by Compose:

```sh
sbx policy allow network '**'
```

This rule applies to all local sandboxes. See the [Docker network policy
reference](https://docs.docker.com/reference/cli/sbx/policy/allow/network/).

During preparation and teardown, the workflow's Node commands allow up to
10 minutes for each Docker or `sbx` call. Commands run later inside the sandbox
have no timeout from this workflow. Compose separately waits up to 120 seconds
for services to become ready. The Docker data disk defaults to 10 GB when
creating a sandbox; set `disk_size` to choose another size.

## View sandboxes

To see and manage your sandboxes, run:

```sh
sbx
```

    </tr>
