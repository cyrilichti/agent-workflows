---
title: /done
description: Squash-merge one exact request, then complete its official item.
---

`/done` completes a reviewed delivery when you are ready to merge. It
squash-merges the linked request and completes the official item.

## How `/done` completes delivery

<div className="write-flow done-flow" role="img" aria-label="The done workflow resolves one linked request and item, verifies the agent-inspected label, mergeability, and one done status, then rechecks the request before squash merge. After observing the merged state it completes the item.">
  <div className="write-flow__step write-flow__step--assisted">
    <small>01 · Resolve</small>
    <strong>Verify completion</strong>
    <span>Require <code>agent-inspected</code>, one linked request, mergeability, and one <code>done</code> status.</span>
  </div>

  <span className="write-flow__connector" aria-hidden="true">↓</span>

  <div className="write-flow__step write-flow__step--focus">
    <small>02 · Recheck</small>
    <strong>Squash merge</strong>
    <span>Recheck the same request and head SHA, then merge it when it is still open.</span>
  </div>

  <span className="write-flow__connector" aria-hidden="true">↓</span>

  <div className="write-flow__step write-flow__step--human">
    <small>Outcome</small>
    <strong>Complete item</strong>
    <span>Move the official item to its resolved <code>done</code> state only after observing the merge.</span>
  </div>
</div>

For a request already merged, `/done` only completes the item when needed. If
the merge is observed but item completion fails, it reports a partial result
with the item transition as the remaining action. A changed or blocked request
stops before merge.

## What `/done` does

<table className="workflow-steps">
  <tbody>
    <tr>
      <td>1</td>
      <th scope="row">Preflight</th>
      <td>Resolve one official item and its linked request, require <code>agent-inspected</code>, and verify the remaining operations.</td>
    </tr>
    <tr>
      <td>2</td>
      <th scope="row">Recheck</th>
      <td>Require the request identity, branches, state, and head SHA to match the initial read.</td>
    </tr>
    <tr>
      <td>3</td>
      <th scope="row">Merge</th>
      <td>Squash-merge an unchanged open request and observe its merged state. Skip the merge when already merged.</td>
    </tr>
    <tr>
      <td>4</td>
      <th scope="row">Finish</th>
      <td>After observing the merged request, move the official item to <code>done</code> and report both results.</td>
    </tr>
  </tbody>
</table>
