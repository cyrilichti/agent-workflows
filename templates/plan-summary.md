# Plan Summary

Use when presenting a created plan to the developer before approval.

## Format (Markdown)

```markdown
## Plan Ready

Plan: <plan file link>

### Objective

<objective>

### Expected Outcome

<expected outcome>

### Todos

- <todo title>
- <todo title>
```

## Rules

* Use `.cursor/plans/<filename>` for the plan link.
* Show todo titles only.
* Do not include the full plan body.
