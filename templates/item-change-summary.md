# Item Change Summary

Use this template after a localized revision to a proposal that has already
been presented completely.

## Format (Markdown)

```markdown
**Changes**

**Added**

- <concise addition>

**Modified**

- <concise before-to-after change>

**Removed**

- <concise removal>
```

## Rules

- Compare the revised proposal with the last proposal shown to the user.
- Use bold inline labels instead of section headings.
- Include only additions, modifications, and removals that affect item
  content.
- Omit every empty category.
- Keep entries concise while preserving exact identifiers and meaningful
  wording.
- Do not include unchanged content, review notes, provider metadata, or
  orchestration details.
- Use `../templates/item-preview.md` instead when the title or overall
  structure changes, several sections change materially, or the user asks for
  the complete proposal.
