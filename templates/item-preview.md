# Item Preview

Use this template when presenting one proposed item for confirmation.

## Format (Markdown)

```markdown
### <item title>

<free-form Markdown body>
```

## Rules

- Use the title value as an H3 heading so the proposal remains subordinate to
  the surrounding conversation.
- Render the body directly below the title and preserve its Markdown.
- Do not display `Title` or `Body` field labels.
- Do not synthesize, restructure, or add provider metadata.
- Keep any Skill announcement outside the preview.
