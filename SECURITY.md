# Security Policy

## Supported versions

Security reports are evaluated against the latest version of the `main` branch.

## Report a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Use [GitHub private vulnerability reporting](https://github.com/cyrilichti/agent-workflows/security/advisories/new) to send the report directly to the maintainers.

Include enough detail to understand and reproduce the issue, such as the
affected version or commit, impact, reproduction steps, and a proof of concept
when safe to share.

## What happens next

Maintainers will acknowledge the report, assess its impact, and coordinate a
fix before public disclosure. Please allow time for that process and avoid
sharing the vulnerability publicly until a resolution is available.
