# Code of Conduct

## Our commitment

We want Agent Workflows to be a constructive space for everyone who uses,
evaluates, or contributes to the project.

## Expected behaviour

- Be respectful and constructive in issues, pull requests, and discussions.
- Focus feedback on ideas, code, and outcomes rather than people.
- Assume good intent, ask for clarification, and help others participate.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, intimidation, and publishing
private information without permission are not acceptable.

## Enforcement

Maintainers may remove content, reject contributions, or limit participation
when behaviour conflicts with this code. If you see a problem, open a GitHub
issue with the context needed for maintainers to act; do not publish sensitive
personal information.
